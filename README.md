# Study Together ☕

감성적인 카페 분위기의 개인/친구 캠스터디 웹앱 첫 버전입니다. 기존 SNOB 프로젝트와 별개입니다.

## 현재 구현된 기능
- 반응형 홈 대시보드
- 뽀모도로 25분 / 짧은 휴식 5분 / 긴 휴식 15분
- 집중 완료 기록, 오늘/최근 7일 통계
- 오늘의 목표, 체크리스트 추가/완료/삭제
- 브라우저 localStorage 저장
- PeerJS를 이용한 실시간 웹캠/마이크 연결 시도, 초대 링크 복사
- 카메라/마이크 토글, 화면 공유 시도

## 실행 방법
1. ZIP 압축을 풉니다.
2. `index.html`을 VS Code에서 엽니다.
3. 카메라 기능을 테스트하려면 VS Code의 Live Server 같은 로컬 HTTPS/localhost 서버로 실행하세요. 브라우저에서 파일을 직접 여는 `file://` 방식은 카메라 권한이 제한될 수 있습니다.
4. GitHub 저장소를 새로 만들고 파일을 업로드합니다.
5. GitHub 저장소의 **Settings → Pages**에서 배포 소스를 `Deploy from a branch`, 브랜치 `main`, 폴더 `/ (root)`로 설정합니다.

## GitHub Pages 배포
- 별도의 빌드 과정은 없습니다. `index.html`, `css/`, `js/`를 저장소 루트에 두면 됩니다.
- 배포 후 `https://계정명.github.io/저장소명/` 주소로 접속합니다.
- GitHub Pages는 HTTPS를 제공하므로 카메라 권한을 요청할 수 있습니다.

## 캠스터디 연결에 관한 중요 안내
이 프로젝트는 PeerJS의 공개 클라우드 시그널링 서비스를 기본 설정으로 사용합니다. 공개 서비스의 가용성이나 네트워크/방화벽 설정에 따라 연결이 되지 않을 수 있으며, 이는 상용 서비스 수준의 보장이나 개인 서버가 아닙니다. 친구 초대 링크를 통해 연결할 때 양쪽 모두 브라우저에서 카메라/마이크 권한을 허용해야 합니다. 화면 공유는 브라우저가 지원해야 하며 일부 환경에서는 공유 트랙 전환이 제한될 수 있습니다.

현재 방 이름/초대 링크를 가진 사람만 입장할 수 있도록 하는 계정·비밀번호 기반 접근 제어, 채팅, 여러 참가자 안정화, 연결 복구, 사용자 인증은 포함되지 않았습니다. 링크는 비밀 초대장처럼 취급하고 신뢰하는 사람에게만 공유하세요. 실사용 전에는 관리형 WebRTC 서비스 또는 자체 시그널링 서버, 접근 제어, 오류 처리, 개인정보 안내를 추가하는 것을 권장합니다.

## 데이터 저장
공부 기록과 체크리스트는 현재 브라우저의 `localStorage`에 저장됩니다. 다른 기기와 자동 동기화되지 않으며 브라우저 데이터 삭제 시 사라질 수 있습니다.
